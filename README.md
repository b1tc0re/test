# Dilexy UI

Vue 3 component library built on Nuxt UI.

## Development

```bash
bun install
bun run dev
```

## Verification

```bash
bun run check
bun run pack
```

Runtime output is written only under `build/`:

```text
build/
├── cache/
├── coverage/
├── dist/
├── package/
└── storybook-static/
```

See [CONTRIBUTING.md](./CONTRIBUTING.md) for component rules and release checks.
